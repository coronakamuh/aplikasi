# Macrondroit

Aplikasi Android mandiri untuk jadwal, pengingat, dan otomatisasi, dengan tema berwarna yang bisa diganti. Dibuat untuk Samsung M30s. Tidak memakai aplikasi kalender, jam, atau pengingat bawaan. Data tersimpan di HP.

## Tahapan

1. Kerangka, tema, tampilan utama (v1.0, dihaluskan di v1.1)
2. Jadwal dan pengingat (v2.0)
3. Otomatisasi (v3.0): senyap, suara normal, mode pesawat (layanan aksesibilitas), buka aplikasi
4. Cadangan ke file, panduan izin, penyempurnaan

## Membuat APK

1. Buka tab **Actions** di repository ini
2. Pilih **Build APK**, lalu **Run workflow** (juga otomatis setiap push ke `main`)
3. Setelah hijau, buka run tersebut dan unduh **Macrondroit-APK** di bagian Artifacts
